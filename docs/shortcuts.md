# Keyboard shortcuts

## Windows, tabs and panes

| Keys | Action |
|---|---|
| ⌘T / ⌘N | New tab / new window |
| ⇧⌘T | Reopen the tab closed last |
| ⌘D / ⇧⌘D | Split right / split down |
| ⌃⌘←→↑↓ | Split toward the arrow: left, right, up, down |
| ⌘W / ⇧⌘W | Close pane / close window |
| ⌘] / ⌘[ | Next / previous pane |
| ⌥⌘←→↑↓ | Focus the pane in that direction |
| ⇧⌘] / ⇧⌘[, ⌃⇥ | Next / previous tab |
| ⌘1…⌘9 | Go to tab |
| ⇧⌘R | Rename tab |
| ⇧⌘P | Command palette |
| ⌘, | Settings |

## Terminal

| Keys | Action |
|---|---|
| ⌘↑ / ⌘↓ | Previous / next command |
| ⇧⌘C / ⇧⌘A | Copy / select the last command's output |
| ⌘K | Clear buffer |
| ⌘F, ⌘G, ⇧⌘G | Find in the scrollback, next match, previous match |
| ⌘E | Find the selected text |
| ⇧⌘F | Find in all panes: every pane's commands and output, in every window, in the Commands sidebar |
| ⌘+ / ⌘− / ⌘0 | Font size |
| ⇧⌘B | Switch branch |
| ⌘-click | Open a file or folder named in the output (`ls`, `git status`, `file.swift:42:7`), or a link |

## Command line (zsh)

| Keys | Action |
|---|---|
| ↑ | Previous command, with the history menu (at the prompt): ↑ / ↓ step through it, Return runs it, Esc goes back |
| ⌃R, ⌘Y | History search (⌃R at the prompt, ⌘Y anywhere) |
| →, ⌥→ | Take the suggested command, or its next word |
| ⌘← / ⌘→ | Move to the start / end of the line |
| ⇧⌘← / ⇧⌘→ | Select to the start / end of the line |
| ⌘⌫ | Delete to the start of the line |

## Sidebars

| Keys | Action |
|---|---|
| ⇧⌘E | Show / hide the file tree |
| ⇧⌘I | Show / hide Intel |
| ⇧⌘L | Show / hide the Commands sidebar |
| ⇧⌘F | Commands sidebar, All Panes, with the keyboard in its filter |
| Return | Open the selected item; in the Commands sidebar, go to the command |
| Space | Commands sidebar: show the command's output |
| → / ← | Intel: open / close a folder |
| ⌘C | Copy the selected path or command |
| ⌘F | Filter |
| Esc | Back to the terminal |

## Intel forms

| Keys | Action |
|---|---|
| Return | Put the command on the command line |
| ⌘Return | Run it / save the form |
| Esc | Close the form |

## Editor

| Keys | Action |
|---|---|
| ⌘S | Save |
| ⌘W, ⌥⌘W | Close the file (⌘W while the editor has the keyboard, ⌥⌘W from anywhere) |
| ⌘/ | Toggle comment |
| Tab / ⇧Tab | Indent / outdent the selected lines |
| ⇧⌘V | Markdown: switch between the source and the preview |
